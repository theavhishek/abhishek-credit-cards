## Credit-card portfolio

The portfolio currently presents:

- **51 credit cards**
- **22 banks and issuers**
- **24 RuPay cards**
- **11 partner cards**

Cards are grouped by issuer and can be searched or filtered by bank, payment network, lifetime-free status, RuPay, partner ownership and cashback type. Each entry displays the card name, network, reward category and the available fee or ownership indicator.

## Bank-support directory

The directory covers **26 banks and issuers**, with the contact details currently maintained on the website.

It includes:

- Search by bank, email address or phone number
- Expandable bank sections
- Tap-to-call and tap-to-email actions
- One-click copy controls
- Customer-care, Nodal Officer and Principal Nodal Officer levels where listed

Bank contact details can change. Confirm important information through the relevant bank’s official website before acting on it.

## Interface

- Responsive desktop and mobile layouts
- Shared navigation and footer across the functional pages

- Cal Sans variable typography
